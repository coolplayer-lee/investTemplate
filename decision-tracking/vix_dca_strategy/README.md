## 执行规则

- 每两周周二执行一次，序列为2026-09-01、09-15、09-29……
- 使用定投日前一个美股交易日的VIX收盘值。
- 513110按定投日收盘价模拟成交。
- 每个定投日都买入，不使用趋势倍率，不根据VIX卖出。
