## 2. 为什么模型仍不知道何时买卖

模板已经要求买入区间、退出条件、量化证伪指标和观察清单，问题是存量报告没有全部落实，且模板保留不少案例式表述。

| 缺口 | 本轮实际证据 | 对自动化的影响 |
|---|---|---|
| 买入门槛未转为可执行决策 | 两报告第44行均采用FCF收益率≥8%、股息率≥5%等组合条件，但缺少有效日期、完整指标值及执行数量 | 到某个股价并不意味着所有条件都成立 |
| 缺少获利退出依据 | 两报告第46行仅定义证伪/治理退出，状态文件却有天津4.5、华润9.0的卖出价 | 未找到状态价格与报告估值推导的对应关系，不能据此自动卖出 |
| 证伪标准模糊 | 华润“应收周转显著恶化”“净负债/FCF继续上升”；天津“利润不能转化为母公司现金” | 缺基准、阈值、期间和证据，模型可能随意解释 |
| 时间条件嵌套 | 华润某条为“归母利润连续两年下降”，总退出又要求“连续两个披露期成立” | 到底两年还是更久不能擅自决定 |
| 动作不唯一 | 报告风险表出现“退出或转为事件观察” | 无法确定卖多少、何时执行 |
| 案例与通用规则易混 | 第七章7.3列“盈利80%退出”的百胜中国案例、“周期价格70%/90%分位” | 案例不能泛化；周期指标及统计窗口也需按标的明确 |
| 存量报告缺更新 | 两份报告仍写截至8月20日缺2026H1，并指定新业绩披露触发复核 | 新业绩线索出现时应先重估，而非一直沿用旧目标 |
| 报告与实际持仓冲突 | 两份报告当前仓位写0%；实际天津40000股、华润17000股 | 报告的研究状态不能代替账本当前状态 |

另有明确规则一致性问题：第七章商业模式矩阵给C级5%上限，后面的“弹性差”示例又给C级8%。统一上限与取最小值规则应优先，示例需在后续模板修订中同步清理，不能让模型自行择宽执行。

| 字段 | 要求 |

| 规模 | 目标仓位或股数，受现金、现有仓位、整手约束 |
